# Структура портфолио

## 1. Читатель

Портфолио откроет HR-специалист или тимлид небольшой американской компании, которая ищет junior frontend-разработчика на удалённую работу. У него есть около минуты на каждого кандидата. За это время он хочет понять три вещи: что я умею, что я уже сделала и можно ли это посмотреть вживую. Поэтому работы стоят на главной сразу под коротким представлением, а у каждой есть ссылка на живой сайт.

## 2. Структура сайта

Не больше четырёх типов страниц:

1. **Главная**: имя, одна строка о себе (frontend-разработчик, HTML · CSS · JS), три работы-превью, ссылка на контакты.
2. **Список работ**: все проекты карточками, у каждой название, короткое описание и ссылка на живой сайт.
3. **Страница кейса**: одна работа подробно: что за проект, какие технологии, что было сложным, что получилось, скриншот и ссылки.
4. **Контакты**: email, GitHub, как со мной связаться.

## 3. Материалы: три работы

### 1. Cafélune (кофейня)
- **Описание:** одностраничный сайт кафе с карточками меню и формой заказа.
- **Технологии:** HTML, CSS, JavaScript.
- **Особенность:** три языка (русский, английский, турецкий).
- **Живой адрес:** https://vanessacalliope.github.io/My-portfolio/cafelune/

### 2. V. Access Card (ID-карта)
- **Описание:** интерактивная карточка разработчика, которая наклоняется за мышью или пальцем.
- **Технологии:** HTML, CSS, JavaScript.
- **Особенность:** анимация реагирует на движение курсора и касание на телефоне.
- **Живой адрес:** https://vanessacalliope.github.io/My-portfolio/holo-id-card.html

### 3. Мой Блог
- **Описание:** блог, где можно добавлять и удалять записи. Записи сохраняются в браузере (localStorage).
- **Технологии:** HTML, CSS, JavaScript.
- **Особенность:** переключатель языков (RU, EN, TR) и темы.
- **Живой адрес:** https://vanessacalliope.github.io/My-portfolio/blog.html
